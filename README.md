# unrot-daily-retention-prototype-anti

A production-shaped interactive prototype designed to improve Day 1 retention for Unrot.

## Product hypothesis

Users are more likely to return the next day when they:
1. Choose a clear learning goal.
2. Receive a relevant five-minute lesson.
3. Complete a meaningful learning action.
4. See exactly what they will learn tomorrow.
5. Set an optional reminder.
